# Security Policy

## Supported Versions

Latest `main` and the newest crates.io release. Older versions get fixes
only via upgrade.

## Reporting a Vulnerability

Open a private report via
[GitHub Security Advisories](https://github.com/bejiihiu/lotus-lantern/security/advisories/new)
— do not file a public issue. Include affected version, strip model if
hardware-related, and repro steps. Expect a first response within 72 hours.
